# Trgovina - kasa, nabava, zaliha

Program za trgovinu (Python + SQLite) koji čita podatke iz programa Roba.
Ovdje je samo kod programa, bez ikakvih podataka trgovine.

- Instalacija: `Trgovina_Setup_<verzija>.exe` (gradi se s `instalacija/build.sh`, treba makensis).
- Nadogradnja: u kasi Postavke > Provjeri nadogradnju. Program uspoređuje `verzija.txt`
  ovdje s instaliranom i skida datoteke iz korijena repozitorija (podaci ostaju).
- Nova verzija: promijeni kod, povećaj broj u `verzija.txt`, commit na `main`.
